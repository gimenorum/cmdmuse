# ADR-4 端末の代替画面に入らず、行エディタとして動く

| 項目 | 値 |
|---|---|
| 状態 | 採用 |
| 日付 | 2026-09-05 |
| この決定を導いたもの | 目的 — シェルの代わりとして使えること |

**状況** — bubbletea のような TUI ライブラリは通常、端末の代替画面バッファに入って画面全体を描く。
`vim` や `less` と同じ挙動で、終了すると元の画面に戻る。

**決定** — 代替画面に入らない。プロンプト1行と、その下に候補や補完を描く。
確定した行の実行結果は端末にそのまま流す。

**検討した代替案**

| 案 | 採らなかった理由 |
|---|---|
| 全画面 TUI にする | 実行結果が終了時に消える。シェルの代わりとして使えない |
| 別ペインに候補を出す | tmux などの多重化ソフトに依存する。単一バイナリで完結しない |

**結果**

- 得るもの — 通常のシェルと同じように、入力も実行結果もスクロールバックに残る
- 代償1 — 再描画を自分で管理する必要がある。描画が保留されることがあり、
  端末を取得しても何も見えない状態が起こりうる (キーを1つ送ると現れる)
- 代償2 — 候補の一覧が端末の高さに収まらない場合、自前で窓を動かす必要がある
